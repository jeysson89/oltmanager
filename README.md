# OLT Manager

Веб-панель для управления OLT (EPON/GPON/VSOL) и абонентскими устройствами ONU.

## Возможности
- Добавление/редактирование OLT-устройств
- Сканирование портов, получение ONU, MAC/SN, статусов, сигналов
- Интеграция с биллингом для поиска адресов
- Управление ONU: перезагрузка, удаление, SLA 1Gbps, blacklist
- Мониторинг доступности устройств (пинг)
- Статистика сигналов с трендами
- Ограничение доступа по IP, журнал входов

## Установка (автоматическая)
```bash
sudo bash install.sh

## Дополнительные функции (добавлены в процессе разработки)
- **Графики сигналов** – интерактивные графики изменения сигнала (Chart.js).
- **Массовые операции** – перезагрузка/удаление нескольких ONU через чекбоксы.
- **Сохранение сигналов для всех ONU** – даже офлайн-устройства попадают в историю.
